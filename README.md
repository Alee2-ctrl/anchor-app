# Anchor

An ADHD-friendly app for one thing at a time: focus sprints, an idea parking lot, a decision helper and a routine/habit tracker with Bloop and home-screen widgets.

## Download (Android)

**[Download the latest Anchor.apk](https://github.com/Alee2-ctrl/anchor-app/releases/latest/download/Anchor.apk)**

Open the link on your Android phone or tablet, open the downloaded file, and allow "Install unknown apps" if asked.

All versions are listed on the [Releases page](https://github.com/Alee2-ctrl/anchor-app/releases).
